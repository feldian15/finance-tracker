# Glossary

## Applied Filters

Filter values that have been submitted to the transactions list, either by clicking **Apply Filters** on the transactions page or by navigating from a dashboard category drilldown.

Applied filters are the only filters that change the displayed transactions.

## Draft Filters

Filter values currently shown in the transactions page controls. Draft filters do not change the displayed transactions until they become applied filters.

## Clear Filters

An action that removes draft filters from the transactions page controls without changing the currently displayed transactions.

## Dashboard Category Drilldown

Navigation from a spending category on the dashboard to the transactions page with that category already applied as a filter.

## Dashboard Reporting Period

The whole-month reporting window selected on the dashboard for summary and category spending reports.
_Avoid_: Date range, custom period

## Uncategorized Transaction

A transaction that has no category assigned yet and still needs user review before spending reports are fully clean.
_Avoid_: Unmatched transaction, uncategorized item

## Target Amount

The estimated monthly amount for a category.
_Avoid_: Budget, period target

## Expected Amount

The target amount scaled by the number of whole months in the selected dashboard reporting period.
_Avoid_: Prorated target, daily target

## Target Threshold

The monthly target reference line shown while hovering a dashboard chart series. For a category series this is the category's target amount, and for a reporting group series this is the sum of target amounts for all categories in that reporting group.
_Avoid_: Expected line, threshold budget

## Average Line

The reference line shown while hovering a dashboard chart series, calculated from the visible monthly points for that series.
_Avoid_: Mean guide, baseline

## Favorability

Whether a category's actual amount is better or worse than its expected amount for the selected dashboard reporting period. Lower spending is favorable for expenses, while higher contributions are favorable for savings and investments.
_Avoid_: Good/bad color, positive/negative variance
